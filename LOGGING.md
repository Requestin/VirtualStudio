# Система логгирования VirtualStudio

## Обзор

Проект VirtualStudio использует централизованную систему логгирования для отслеживания работы приложения, операций с файлами, базой данных и обработки ошибок.

## Структура логов

### Файлы логов

Все логи сохраняются в папке `logs/` в корне проекта:

- `virtualstudio.log` - основной лог приложения (ротация каждый месяц, хранится 12 месяцев)
- `file_operations.log` - операции с файлами (ротация каждые 2 недели, хранится 6 месяцев)
- `database.log` - операции с базой данных (ротация каждые 2 недели, хранится 6 месяцев)

### Ротированные файлы

При ротации создаются файлы с суффиксами дат:
- `virtualstudio.log.2025-01` - основной лог за январь 2025
- `file_operations.log.2025-01-15` - файловые операции за 15 января 2025
- `database.log.2025-01-15` - операции с БД за 15 января 2025

### Логгеры

1. **VirtualStudio** (основной) - общие операции приложения
2. **VirtualStudio.FileOperations** - операции с файлами
3. **VirtualStudio.Database** - операции с базой данных

## Уровни логгирования

- **INFO** - информационные сообщения о ходе работы
- **DEBUG** - детальная отладочная информация
- **WARNING** - предупреждения о потенциальных проблемах
- **ERROR** - ошибки в работе приложения

## Что логгируется

### Запуск приложения
- Инициализация системы логгирования
- Загрузка модулей
- Создание директорий
- Подключение к базе данных

### Навигация пользователей
- Переходы между страницами
- Выбор телеканалов
- Доступ к модулям

### Операции с файлами
- Сохранение изображений
- Удаление файлов
- Дублирование между каналами
- Создание аватаров
- Перемещение в DELETED

### Операции с базой данных
- Добавление персон
- Удаление персон
- Подключение к БД

### Обработка изображений
- Удаление фона
- Создание временных файлов
- Обработка ошибок

### Работа с Excel
- Обновление данных модулей
- Чтение данных из файлов

## Формат логов

```
YYYY-MM-DD HH:MM:SS - LoggerName - LEVEL - function:line - Message
```

Пример:
```
2025-06-02 12:23:51 - VirtualStudio - INFO - <module>:25 - Модуль удаления фона успешно загружен
```

## Ротация логов

### Временная ротация (новая система)

- **Основной лог**: ротируется каждые 30 дней (месяц), хранится 12 файлов (год)
- **Операции с файлами/БД**: ротируются каждые 14 дней, хранится 12 файлов (~6 месяцев)
- Ротация происходит автоматически в полночь
- Старые файлы автоматически удаляются после превышения лимита
- Файлы сохраняются с датовыми суффиксами для удобства

### Преимущества новой системы

1. **Предсказуемость** - файлы создаются в определенные даты
2. **Удобство архивирования** - можно легко найти логи за конкретный период
3. **Автоматическая очистка** - старые файлы удаляются автоматически
4. **Размер под контролем** - исключается рост файлов до критических размеров

### Ручная очистка старых логов

```python
from logger_config import cleanup_old_logs

# Удаляет все файлы логов старше 1 года
cleanup_old_logs()
```

## Настройка

Конфигурация логгирования находится в файле `logger_config.py`:

- **interval** - интервал ротации в днях (30 для основного, 14 для операций)
- **backupCount** - количество файлов для хранения (12 для основного, 12 для операций)
- **when** - время ротации ('midnight' - в полночь)
- **suffix** - формат суффикса даты ("%Y-%m" или "%Y-%m-%d")

### Примеры настройки

```python
# Ротация каждую неделю, хранить 4 недели
TimedRotatingFileHandler(
    log_file,
    when='midnight',
    interval=7,
    backupCount=4,
    encoding='utf-8'
)

# Ротация каждый день, хранить 30 дней
TimedRotatingFileHandler(
    log_file,
    when='midnight',
    interval=1,
    backupCount=30,
    encoding='utf-8'
)
```

## Мониторинг

### Просмотр текущих логов

```bash
# Windows PowerShell
Get-Content logs\virtualstudio.log -Wait

# Bash
tail -f logs/virtualstudio.log
```

### Просмотр архивных логов

```bash
# Логи за январь 2025
Get-Content logs\virtualstudio.log.2025-01

# Операции с файлами за 15 января 2025
Get-Content logs\file_operations.log.2025-01-15
```

### Поиск ошибок во всех логах

```bash
# Windows PowerShell
Select-String -Path logs\*.log -Pattern "ERROR"

# Bash
grep "ERROR" logs/*.log
```

### Анализ логов за период

```bash
# Все логи за январь 2025
Select-String -Path logs\*.2025-01* -Pattern "INFO"

# Ошибки в файловых операциях за определенную дату
Select-String -Path logs\file_operations.log.2025-01-15 -Pattern "ERROR"
```

## Управление дисковым пространством

### Автоматическое управление

- Старые файлы автоматически удаляются при превышении `backupCount`
- Основной лог хранится 1 год (12 месяцев)
- Логи операций хранятся ~6 месяцев (12 файлов по 2 недели)

### Ручное управление

```python
# В коде приложения или отдельном скрипте
from logger_config import cleanup_old_logs

# Удаление всех логов старше года
cleanup_old_logs()
```

### Мониторинг размера

```bash
# Размер папки логов (Windows)
Get-ChildItem logs\ -Recurse | Measure-Object -Property Length -Sum

# Размер папки логов (Linux/Mac)
du -sh logs/
```

### Архивирование

```bash
# Создание архива старых логов (Windows)
Compress-Archive -Path logs\*.2024-* -DestinationPath logs_archive_2024.zip

# Создание архива старых логов (Linux/Mac)
tar -czf logs_archive_2024.tar.gz logs/*.2024-*
```

## Рекомендации по эксплуатации

1. **Мониторинг места** - проверяйте размер папки logs/ раз в месяц
2. **Архивирование** - создавайте архивы старых логов перед их удалением
3. **Анализ трендов** - сравнивайте логи разных месяцев для выявления проблем
4. **Настройка ротации** - адаптируйте интервалы под интенсивность использования
5. **Резервное копирование** - включайте папку logs/ в резервные копии

## Устранение неполадок

### Логи не ротируются
- Проверьте, что приложение работает непрерывно
- Убедитесь, что время системы корректно
- Проверьте права доступа к папке logs/

### Слишком много файлов логов
- Уменьшите `backupCount` в logger_config.py
- Используйте `cleanup_old_logs()` для ручной очистки
- Увеличьте интервал ротации

### Большой размер отдельных файлов
- Уменьшите интервал ротации (например, с 14 до 7 дней)
- Увеличьте уровень логгирования (WARNING вместо INFO)

### Ошибки кодировки
- Убедитесь, что используется UTF-8 encoding
- Проверьте настройки консоли Windows

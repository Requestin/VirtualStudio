# Virtual Studio - Система управления графическим оформлением для телевидения

## Общее описание
Это веб-приложение на Flask, предназначенное для управления графическим оформлением телевизионного контента. Система позволяет оператору графической станции подготавливать и управлять графическими элементами для различных типов экранного оформления.

## Основные функции:

1. **Управление шаблонами графики:**
   - Поддержка различных типов графических шаблонов (1win_v1, 1win_v2, 1win_v3, 2win_v1 и т.д.)
   - Каждый шаблон предназначен для разного количества участников (от 1 до 3)

2. **Работа с персональными данными:**
   - Добавление новых персон с ФИО и должностью
   - Загрузка и обработка фотографий
   - Автоматическое удаление фона с фотографий
   - Создание прокси-версий изображений для предпросмотра

3. **База данных:**
   - Хранение информации о персонах в SQLite
   - Быстрый поиск и повторное использование данных
   - Возможность выбора существующих персон из базы

4. **Интеграция с Excel:**
   - Автоматическое обновление Excel-файлов для графических машин
   - Структурированное хранение данных по разным типам графики
   - Синхронизация с графическими станциями

## Технические особенности:

1. **Стек технологий:**
   - Backend: Python + Flask
   - База данных: SQLite
   - Обработка изображений: PIL, локальная модель для удаления фона (BiRefNet)
   - Работа с данными: Pandas

2. **Обработка изображений:**
   - Автоматическое удаление фона с помощью локальной нейросети BiRefNet
   - Создание прокси-версий для предпросмотра
   - Поддержка различных форматов

3. **Безопасность:**
   - Проверка типов файлов
   - Безопасное хранение данных
   - Обработка ошибок

## Процесс работы:

1. Оператор выбирает тип графического шаблона
2. Вводит данные участников:
   - ФИО
   - Должность
   - Загружает фотографию
3. Система автоматически:
   - Обрабатывает фото
   - Сохраняет данные в базу
   - Обновляет Excel-файл
4. Графическая станция считывает данные из Excel
5. Оператор может выдать графику в эфир

## Системные требования:
1. Python 3.x
2. Основные зависимости:
   - Flask 3.0.3 (веб-фреймворк)
   - Pandas 2.2.2 (работа с данными)
   - Pillow 10.4.0 (обработка изображений)
   - OpenCV Python 4.10.0 (обработка изображений)
   - PyTorch (для BiRefNet модели удаления фона)
   - Transformers (для BiRefNet модели удаления фона)
   - SQLite (встроенная база данных)

## Установка:

### Для Windows:
1. Запустите `.\install.ps1`
2. Для установки PyTorch с поддержкой CUDA запустите `.\install_torch.ps1`
3. Дождитесь сообщения об успешной установке
4. Запустите `.\run.ps1`

### Для Linux/Unix:
1. Выполните `chmod +x install.sh install_torch.sh`
2. Запустите `./install.sh`
3. Для установки PyTorch с поддержкой CUDA запустите `./install_torch.sh`
4. Дождитесь сообщения об успешной установке
5. Запустите `python3 app.py`

### Ручная установка (если скрипты не работают):
```bash
pip install -r requirements.txt
# Для CUDA поддержки
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
python app.py
```

### После установки веб-интерфейс будет доступен по адресу http://localhost:5000

## Интеграция с локальной нейросетью для удаления фона

В проекте используется локальная нейросеть BiRefNet для удаления фона с фотографий. Функция `process` импортируется напрямую из модуля background-removal, что обеспечивает более эффективную обработку без необходимости запуска дополнительного сервиса.

### Переключение между CPU и CUDA

По умолчанию модель настроена на работу на CPU для максимальной совместимости. Для использования GPU (значительно ускоряет обработку) отредактируйте файл `bg_remove/app.py`:

1. Найдите строки:
```python
# Для использования CUDA раскомментируйте следующую строку и закомментируйте строку с 'cpu'
# DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
DEVICE = "cpu"
```

2. Измените их на:
```python
# Для использования CUDA раскомментируйте следующую строку и закомментируйте строку с 'cpu'
DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
# DEVICE = "cpu"
```

### Требования:
- Для CPU: не требуется дополнительное оборудование
- Для GPU: видеокарта NVIDIA с поддержкой CUDA и минимум 4GB видеопамяти
- PyTorch и другие зависимости, указанные в requirements.txt
